Help

Questions

Tapping Install does nothing.

Open this page in Safari, tick the Terms box and add the DNS profile first. If a signed install still won't start, its certificate may be revoked. Pick another one.

It installed but won't open.

Trust it in Settings › General › VPN & Device Management. If it still closes right away, that install's certificate was revoked. Delete it and try another signed install.

Do I need an account?

No. SafeWatch has no accounts at all. Parental controls are set up on the phone with a PIN.
